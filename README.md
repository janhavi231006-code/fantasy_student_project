# Fantasy Cricket Project

## Overview
This is a **Fantasy Cricket Project** built in Python. It allows users to create and manage their fantasy cricket teams, track player stats, and simulate matches using a local SQLite database. The project is designed as a small-scale, interactive cricket management system.

---

## Project Structure

- `main.py` : The main Python script to run the project.  
- `fantasy_cricket.db` : SQLite database storing player data, teams, and match statistics.  
- `README.md` : This file with project description and usage instructions.

---

## Features

1. **Team Creation**: Users can select players to form their fantasy cricket team.  
2. **Player Stats**: Tracks runs, wickets, and other player statistics.  
3. **Match Simulation**: Simulates matches and updates scores based on players’ performances.  
4. **Database Integration**: Uses SQLite to store all user and player data.
